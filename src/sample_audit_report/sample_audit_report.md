# Sample Audit Report (synthetic demonstration)

Report identifier: MRFS-SAMPLE-2026-W09-W12. Every figure is produced by `metrics.py` from data generated by `generate_synthetic_audit.py` and can be regenerated with `python generate_sample_audit_report.py`. It is not evidence about any real marketplace.

| Item | Declared value |
|---|---|
| Kind of assessment | platform audit |
| Comparison population | candidates: synthetic candidate set (all listings drawn for the request) |

| K; ordered depth for E2 | 10; 50 |
| Size cohorts | quartiles of completed orders in the 12 calendar months before audit start; Small at or below the lower quartile, Large at or above the upper quartile, Medium between |
| Tenure cohorts | New if the opening date is later than 12 calendar months before audit start |
| Thresholds (E1, O3) | MRFS defaults: Review line 0.80, Monitor line 0.85, applied to the whole 95% interval |
| Thresholds (S1) | MRFS defaults: Monitor line -10%, Review line -20% |
| Data-quality acceptance criteria | rows without a cohort label at most 1.0%; events excluded at most 1.0%; events with an incomplete top K at most 1.0% |
| Windows | audit window weeks 9 to 12; monitoring window 1 week; 4 baseline windows |

Statuses apply to the declared candidate stage only. A status indicates a potential disparity that calls for investigation; it does not establish unfair treatment or its cause.

## 8. What the generator did

For checking the result against the truth: ranking version v2 (weeks 9 to 12) added a score penalty of 0.024 to listings of Small sellers, as defined by completed orders, and multiplied their click probability by 0.8. Version v1 ignored cohort. Tenure was never used by either version. The observed click-through ratio is lower than 0.8 because penalised listings also sit lower within the top 10, where click probability is lower: O1 to O3 are not adjusted for position.
