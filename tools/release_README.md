# MRFS — Marketplace Ranking Fairness Standard

Version 2.0.0, published 11 October 2026. A method for auditing how marketplace ranking and recommendation systems distribute top-ranked positions across groups of sellers, with stated uncertainty, and for governing what happens when an audit finds a potential disparity.
